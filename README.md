# OlimpBD
База данных была разработана в ходе VII Международной дистанционной олимпиады "Проектирование и разработка баз данных", организуемой ГАПОУ СО ЕМК.

## Работа получила третье место

# Об олимпиаде
В тз нам предоставили макет мобильного приложения в Figma. По нему нужно было создать базу данных, учитывая все сущности и отношения, изображённые на макете
Необходимо было спроектировать создать БД на одной из предложенных СУБД, заполнить её тестовыми данными, предоставить скрипт и ERD. Также необходимо было написать подробную спецификацию, затронув все аспекты БД, её сущности, объекты, инструкция к развёртыванию и эксплуатации. При этом спецификация должна быть понятной, максимально простой, так, чтобы не разбирающийся человек смог всё понять.
Дополнительно в этом репозитории я предоставил Docker файл для поднятия этой базы в контейнере.
